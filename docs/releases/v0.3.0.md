# Discord Messages Exporter 0.3.0

A release focused on safer sign-in, clearer diagnostics, and more complete message rendering.

## ✨ Highlights

- **Remember your token on Windows.** Tokens are encrypted with Windows DPAPI for the current Windows account and stored in `token.enc` beside the app settings. Other Windows users and other machines cannot decrypt it.
- **Download logs when something goes wrong.** **Settings → Files → Download logs** produces a bounded diagnostic log with recent server and export activity. Token-like values are redacted.
- **Message counts for every scope.** **Check message count** now reports totals for a whole channel or server, not just one author.
- **Stickers render in the message browser.** Sticker-only messages show the sticker instead of an empty row, with a fallback tile for Lottie or unavailable images.
- **A smaller posting clock.** The heatmap is capped in width with shorter rows, so it takes far less vertical space while keeping its hover and click filters.
- **Cleaner account switching.** Changing tokens clears the previous server/channel selection, so an old target cannot produce a misleading permission error.

## 🛠️ Improved

- Export picker menus now render above the lower library panels instead of being painted underneath them.
- The preview shows message totals with their channel and server context.
- Release downloads now include the platform and architecture in their filenames.
- Bot requests identify the exporter with a DiscordBot user agent that follows the app version.
- The message count check is labeled consistently across author, channel, and server scopes.

## 🐛 Fixed

- Fixed `Unknown Guild` errors after clicking **Choose from lists** with a stale server selected.
- Fixed a token-switch bug where a channel from the previous account stayed selected.
- Fixed picker menus being visually cut off by the Recent exports panel.
- Sticker-filtered messages no longer show only “no text content.”
- Diagnostic logs no longer imply a Windows keychain exists when the DPAPI file is in use.

## 📝 Notes

- Windows token storage requires PowerShell and DPAPI. If neither works, the token stays in memory until the app stops.
- Existing exports do not need a rebuild to show stickers or the new message counts.
- Sticker artwork loads from Discord’s CDN when viewed; exports store sticker IDs and names, not image files, so stickers may not display offline.
- Message totals come from Discord’s search estimate and can differ slightly from the crawler’s final count.
- The self-hosted web console requires Node.js 24 or newer. The desktop app does not.
