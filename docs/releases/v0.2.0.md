# Discord Messages Exporter 0.2.0

A release focused on making an archive easier to search, read, and understand.

## ✨ Highlights

- **Filter messages by content type.** Narrow any search to text, media, images, videos, audio, files, code blocks, links, or stickers. Counts are shown next to each choice.
- **Messages look like messages.** Discord markdown, custom emoji, reactions, replies, mentions, link previews, and embedded media all render in the message browser.
- **Profile pictures everywhere.** Author and mentioned-user avatars are saved with the export and shown in message rows and detail views.
- **A clearer Explorer.** Every export now shows its source channel and server. Recent exports on the dashboard are clickable, and job exports can be removed from the library without deleting the files on disk.
- **Better Insights.** The posting clock is now a filter, charts have designed hover tooltips, custom reaction emoji display as images, and the word cloud fills the panel properly.
- **A simpler identity.** The sidebar now says just **Message Exporter** — no extra labels.

## 🛠️ Improved

- Export cards show source context and have a clearer primary/secondary action layout.
- Calendar and posting-clock filters stay in sync with the message list.
- Insight titles describe the data instead of using the export's name.
- Attachment warnings are clearer when a message's files were not archived.
- A new README with screenshots for the main parts of the app.

## 🐛 Fixed

- Theme colors now reach charts, controls, and the posting clock.
- Activity-chart markers stay circular instead of stretching with the chart.
- Chart and clock tooltips appear next to the pointer instead of being trapped by the glass panel.
- The Author filter no longer overlaps the search field.
- Import drop-zone styling matches the rest of the console.
- Removed confusing numbered module labels from the dashboard.

## 📦 Downloads

- **Windows** — portable 64-bit ZIP. Unzip and run `Discord Messages Exporter.exe`.
- **Linux** — `.deb`, `.rpm`, and AppImage packages.

## 📝 Notes

- Existing exports rebuild their local search index once after upgrading so the new content filters are available. The original JSON files are untouched.
- Attachment downloads remain optional. When skipped, the export keeps Discord's signed CDN links, which expire.
- The self-hosted web console requires Node.js 24 or newer. The desktop app does not.
